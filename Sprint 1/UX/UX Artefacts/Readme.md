# UX Artefacts-Sprint 1
## Overview
UX wireframes created for the GP26 Dynamic Forms platform based on the BA user journey and existing forms in monday.com.

## Designs

### 1. Login Interface
Login interface for authorised users.

### 2. Dynamic Form
Collects common contact information before allowing the user to select a service. The selected service dynamically displays the relevant form fields.

### 3. Client Results Dashboard
Allows the client to select a service category and view the submitted requests.

### 4. Telecommunications Results
This displays telecommunication submissions with search and filtering functionality.
