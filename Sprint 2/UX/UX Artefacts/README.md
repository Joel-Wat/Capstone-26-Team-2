## UX Designer

## UX Prototype Behaviour Specification

This artefact documents the expected user behaviour and UX interactions for the Sprint 2 prototype.

It provides developer guidance for:
- Customer and internal-user prototype flows
- Form validation and feedback
- Login behaviour
- Search and filtering behaviour
- Navigation and interaction labels
- Individual requirement review
- UX requirements requiring further client clarification

## Developer Handoff

The UX specification should be used alongside the finalised Figma wireframes by Dev 1 and Dev 2 during prototype implementation.
